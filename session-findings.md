# Session findings ledger

Append-only log of improvement candidates captured by the `retro` skill.
Each entry is one line, tagged by proposed route:

- `[AGENTS-MD]` — add to a repo's AGENTS.md
- `[SKILL-NEW]` — new skill candidate
- `[SKILL-FIX]` — fix an existing skill's description/trigger/body
- `[AGENT]` — named agent or model-pin question
- `[SCRIPT]` — mechanical helper script inside a skill

A finding with 2+ dated occurrences is evidence, not anecdote — that's the bar
for building the fix. Review with "review my findings".
